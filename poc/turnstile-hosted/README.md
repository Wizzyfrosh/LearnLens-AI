# LearnLens hosted Turnstile challenge page

This is a standalone static page. It is intentionally separate from the Chrome extension bundle because Turnstile needs to run on a normal HTTPS web origin, not inside an extension page's script context.

## Build and verify

From the repository root:

```sh
npm run poc:turnstile-hosted:verify
```

The verify script type-checks the page, runs protocol tests, builds the static site and checks the output bundle for the required boundary conditions.

Build output: `poc/turnstile-hosted/dist/`

## Deployment configuration

Set this public build-time variable only when the extension's stable ID is known:

```text
VITE_ALLOWED_PARENT_ORIGINS=chrome-extension://<32-character-extension-id>
```

Multiple exact Chrome extension origins may be comma-separated. Wildcards, web origins and malformed extension origins are discarded. An empty allowlist means the hosted page rejects all initialization messages.

Do not use a temporary extension ID as a permanent production allowlist. The final Chrome Web Store ID is not known yet.

The Turnstile site key is supplied in the initialization message by the extension. It is public, not a secret. The Turnstile secret is never present in this static app.

## Required HTTPS response headers

Configure the hosting platform to return:
- `Content-Security-Policy` including `script-src 'self' https://challenges.cloudflare.com`, `frame-src https://challenges.cloudflare.com`, and `connect-src 'self' https://challenges.cloudflare.com`.
- `frame-ancestors` restricted to the exact published Chrome extension origin after its ID is fixed.
- `Referrer-Policy: no-referrer`.
- `X-Content-Type-Options: nosniff`.

The HTML also carries a restrictive CSP meta policy for the Turnstile script/frame/connect endpoints and a no-referrer meta tag. The `frame-ancestors` restriction must be an HTTP response header; it is not enforced when supplied through a meta element.

Do not set `X-Frame-Options: SAMEORIGIN` or `DENY`; the page is intentionally loaded as a cross-origin iframe in the extension challenge page.

Before deployment, verify the final headers in a browser and test the exact extension origin. The extension's own Manifest V3 CSP must separately allow `frame-src` for the exact hosted page origin. Do not use broad remote script permissions in the extension.

## Message protocol

The hosted page only accepts `LEARNLENS_TURNSTILE_INIT` from:
1. The direct parent window (`event.source === window.parent`).
2. A configured, exact `chrome-extension://<id>` origin.
3. A message with protocol version 1 and exactly the documented keys.

Initialization fields:
- `requestId`: random UUID generated by the extension for this challenge attempt.
- `siteKey`: public Turnstile site key.
- `action`: server-selected challenge action.
- `cdata`: server-generated session binding.

The page returns:
- `LEARNLENS_TURNSTILE_READY`: generic readiness signal containing no credentials. It is sent to the parent without an origin target because it contains no sensitive data; the parent must check source and origin.
- `LEARNLENS_TURNSTILE_INIT_ACCEPTED`: confirmation to the exact validated extension origin.
- `LEARNLENS_TURNSTILE_TOKEN`: one-time Turnstile response, sent only to the exact validated extension origin.
- `LEARNLENS_TURNSTILE_EXPIRED` or `LEARNLENS_TURNSTILE_ERROR`: non-secret status messages.

Control messages `RESET` and `CANCEL` require the active request ID and exact protocol keys.

## Data boundary

The hosted page must never receive:
- Firebase ID token or refresh token.
- Firebase UID or email.
- Challenge session ID.
- One-time polling credential.
- App Check token.

It receives only the public site key, action, cdata and random request ID. The one-time response token is sent to the direct parent and is not written to a URL, DOM attribute, log, analytics system or browser storage. The extension must validate the hosted origin, iframe source, request ID and token length before calling the authenticated Firebase completion callable.

No Firebase SDK is imported into this page. No Turnstile secret, Firebase credential or server-only value is bundled.
